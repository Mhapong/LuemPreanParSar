# LuemPreanParSar (ลืมเปลี่ยนภาษา)

## โปรเจกต์นี้คืออะไร

เคยไหม ตั้งใจพิมพ์ "สวัสดี" แต่หน้าจอขึ้นว่า `l;ylfu` เพราะลืมกดเปลี่ยนภาษา ต้องลบทิ้งทั้งหมด เปลี่ยนภาษา แล้วพิมพ์ใหม่

โปรเจกต์นี้คือ**โปรแกรมที่แก้ให้อัตโนมัติ** โปรแกรมคอยดูสิ่งที่พิมพ์ พอรู้ว่าพิมพ์ผิดภาษา ก็จะลบ เปลี่ยนภาษา และพิมพ์ใหม่ให้ถูก ผู้ใช้พิมพ์ต่อได้ทันที

| ตั้งใจพิมพ์ | แต่เครื่องตั้งเป็น | หน้าจอขึ้นว่า | โปรแกรมแก้เป็น |
|---|---|---|---|
| สวัสดี | ภาษาอังกฤษ | `l;ylfu` | สวัสดี |
| hello | ภาษาไทย | `้ำสสน` | hello |

โปรแกรมทำงานบน **Linux** ซึ่งยังมีเครื่องมือแบบนี้น้อย (บน Windows และ Mac มีโปรแกรมคล้ายกัน เช่น RightLang และ Punto Switcher)

## ทำงานอย่างไร (แบบสั้นที่สุด)

1. **ฟัง:** คอยดูว่าผู้ใช้กดปุ่มอะไร
2. **ตัดสิน:** ใช้**ปัญญาประดิษฐ์ (AI)** ที่ฝึกจากข้อความภาษาไทยและอังกฤษหลายล้านประโยค ดูว่าสิ่งที่พิมพ์ "ดูเป็นภาษาจริง" หรือ "ดูเหมือนพิมพ์ผิดแป้น"
3. **แก้:** ถ้ามั่นใจว่าพิมพ์ผิด ก็ลบ, เปลี่ยนภาษา แล้วพิมพ์ใหม่ให้

## สำหรับผู้พัฒนา: วิธีเริ่มต้น

ต้องติดตั้ง [uv](https://docs.astral.sh/uv/) ก่อน จากนั้นเปิด terminal ในโฟลเดอร์นี้แล้วพิมพ์

```fish
uv sync                                   # ติดตั้งทุกอย่างที่ต้องใช้
uv run pytest                             # ตรวจว่าโปรแกรมทำงานถูกต้อง
uv run python scripts/verify_layout.py    # ตรวจว่าตารางแป้นพิมพ์ตรงกับของระบบ
```

ใส่ `uv run` นำหน้าคำสั่งเสมอ ไม่ต้อง activate `.venv` เอง
