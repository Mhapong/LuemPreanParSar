**ที่เก็บรูป:** `docs/figures/` ตั้งชื่อไฟล์ตามเลขรูป เช่น `fig03_keyboard.png`

## 1. รูปมี 4 แบบ เลือกให้เหมาะกับสิ่งที่จะแสดง

| แบบ | ใช้แสดงอะไร | ทำอย่างไร |
|---|---|---|
| **A. แผนภาพ** | ขั้นตอนการทำงาน หรือโครงสร้างของระบบ | แปลงจากแผนภาพใน FLOW.md เป็นรูป (ดูข้อ 5) |
| **B. กราฟ** | ผลการทดลอง และสถิติของข้อมูล | ให้โปรแกรมวาดและบันทึกเป็นรูปเอง |
| **C. ภาพหน้าจอ** | พิสูจน์ว่าระบบทำงานจริง เช่น หน้าต่างโปรแกรม หรือแถบงาน | กดปุ่มถ่ายภาพหน้าจอ |
| **D. ข้อความจากหน้าจอ** | ผลลัพธ์ที่เป็นตัวหนังสือในหน้าต่างคำสั่ง (terminal) | **คัดลอกข้อความ** ไปวางในรายงาน ไม่ต้องถ่ายภาพ |

**ทำไมแบบ D ดีกว่าภาพหน้าจอสำหรับตัวหนังสือ:** ตัวหนังสือที่คัดลอกมาจะคมชัด ค้นหาได้ และไม่แตกเมื่อพิมพ์ ใช้ภาพหน้าจอเฉพาะเมื่อต้องการ**พิสูจน์ว่าทำจริง** หรือเมื่อสิ่งที่แสดงเป็นภาพ เช่น หน้าต่างโปรแกรม

## 2. วิธีถ่ายภาพหน้าจอบน Linux Mint

| กดปุ่ม | ได้ภาพอะไร |
|---|---|
| `PrtSc` | ทั้งจอ |
| `Alt + PrtSc` | เฉพาะหน้าต่างที่กำลังใช้ (**ใช้บ่อยที่สุด**) |
| `Shift + PrtSc` | ลากเมาส์เลือกพื้นที่เอง |

รูปจะถูกบันทึกไว้ที่โฟลเดอร์ `Pictures` ของผู้ใช้ จากนั้นย้ายมาไว้ที่ `docs/figures/`

**ก่อนถ่ายหน้าต่างคำสั่ง (terminal)**
1. ขยายตัวอักษรด้วย `Ctrl` + `+` 2–3 ครั้ง ย่อลงในรายงานแล้วจะได้ยังอ่านออก
2. ปรับหน้าต่างให้พอดีกับเนื้อหา ไม่ให้มีที่ว่างเยอะ
3. พิมพ์ `clear` ล้างหน้าจอก่อนรันคำสั่ง
4. ถ้ารายงานพิมพ์ขาวดำ ให้เปลี่ยนเป็นพื้นขาว (Edit → Preferences → Colors)
5. **ตรวจว่าไม่มีข้อมูลลับในภาพ** เช่น รหัสผ่าน หรือรหัสเข้าใช้งานเว็บ

## 4. การอัดวิดีโอสาธิต

**จัดหน้าจอ:** โปรแกรมพิมพ์เอกสารอยู่ซ้าย หน้าต่างของโปรแกรมแก้ภาษาอยู่ขวา หน้าต่างขวาจะแสดงว่าโปรแกรมเห็นอะไร มั่นใจแค่ไหน และตัดสินใจอย่างไร ผู้ชมจะเข้าใจว่า**ทำไม**โปรแกรมถึงแก้

**โปรแกรมอัดหน้าจอ**
- **OBS Studio** (ติดตั้งด้วย `sudo apt install obs-studio`) ใช้ได้ทั้ง Wayland และ X11 **แนะนำ**
- ปุ่มอัดในตัวของ Linux Mint (`Ctrl+Alt+Shift+R`) อาจใช้ได้เฉพาะ X11

**ลำดับการสาธิต (ประมาณ 1 นาที)**
1. แสดงว่าตอนนี้เครื่องตั้งเป็นภาษาอังกฤษ
2. ตั้งใจพิมพ์ "สวัสดีครับ" แต่ลืมเปลี่ยนภาษา → โปรแกรมแก้ให้
3. ตั้งใจพิมพ์ "hello world" ตอนเครื่องตั้งเป็นภาษาไทย → โปรแกรมแก้ให้
4. พิมพ์ `git status` และรหัสผ่านทดสอบ → โปรแกรม**ไม่**แก้ (แสดงว่าไม่ถูกตัวอย่างหลอกหลอก)
5. กดปิดโปรแกรม แล้วพิมพ์ผิดแป้น → โปรแกรมไม่แก้

**ดึงภาพจากวิดีโอมาทำรูปที่ 28:** ใช้คำสั่งด้านล่าง เปลี่ยนเวลา (`00:00:05`) ให้ตรงกับจังหวะในวิดีโอ
```fish
ffmpeg -ss 00:00:05 -i demo.mp4 -frames:v 1 docs/figures/fig28a_before.png
ffmpeg -ss 00:00:07 -i demo.mp4 -frames:v 1 docs/figures/fig28b_after.png
```

## 5. แปลงแผนภาพใน FLOW.md เป็นรูป

**วิธีที่ 1 (ง่ายที่สุด):** เปิดเว็บ https://mermaid.live คัดลอกโค้ดของแผนภาพ 1 ภาพจาก FLOW.md (ส่วนที่อยู่ระหว่าง ` ```mermaid ` กับ ` ``` `) ไปวาง แล้วกด Actions → PNG

**วิธีที่ 2 (ทุกภาพในคำสั่งเดียว):**
```fish
npx -p @mermaid-js/mermaid-cli mmdc -i docs/FLOW.md -o /tmp/flow.md -e png -s 3 -b white
```
จะได้ไฟล์ `flow-1.png` ถึง `flow-5.png` ตามลำดับภาพ (ครั้งแรกจะดาวน์โหลด Chromium ให้อัตโนมัติ) แล้วคัดลอกไปตั้งชื่อใน `docs/figures/` ดังนี้ flow-1 → `fig01_overview.png`, flow-2 → `fig06_data_pipeline.png`, flow-3 → `fig11_training_flow.png`, flow-4 → `fig26_keypress_flow.png`, flow-5 → `fig27_fix_sequence.png` (✅ ทำแล้ว 5 ต.ค.)

**เลือกชนิดไฟล์:** SVG ขยายแล้วไม่แตก เหมาะกับ Word ส่วน PNG ให้ใช้ `-s 3` เพื่อให้ได้ภาพละเอียด
