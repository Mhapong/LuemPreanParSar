# อภิธานศัพท์: คำศัพท์ที่ใช้ในโปรเจกต์

เอกสารนี้อธิบายคำศัพท์ทุกคำที่ใช้ในโปรเจกต์ด้วยภาษาง่ายๆ อ่านได้โดยไม่ต้องมีพื้นฐานด้านคอมพิวเตอร์ เอกสารอื่นในโปรเจกต์จะลิงก์มาที่นี่เมื่อใช้คำศัพท์เหล่านี้

---

## ภาพรวม: กดปุ่ม 1 ครั้ง เกิดอะไรขึ้นบ้าง

ก่อนดูคำศัพท์ทีละคำ ลองดูเส้นทางของการกดปุ่ม 1 ครั้งก่อน คำศัพท์ส่วนใหญ่ในหมวด 1–3 คือชื่อของขั้นตอนในภาพนี้

```
นิ้วกดปุ่มที่มีตัว L
   │
   ▼
คีย์บอร์ดส่งสัญญาณให้คอมพิวเตอร์
   │
   ▼
ระบบปฏิบัติการรู้ว่า "ปุ่มหมายเลข 38 ถูกกด"         ← โปรแกรมของเราแอบดูตรงนี้
   │
   ▼
ระบบดูว่าตอนนี้ตั้งภาษาไว้เป็นอะไร
   ├─ ภาษาอังกฤษ → ได้ตัว "l"
   └─ ภาษาไทย   → ได้ตัว "ส"
   │
   ▼
ตัวอักษรขึ้นในโปรแกรมที่กำลังพิมพ์อยู่
```

**เปรียบเทียบ:** ปุ่มบนคีย์บอร์ดเหมือนบ้านเลขที่ ส่วนตัวอักษรที่ได้เหมือนชื่อคนที่อยู่ในบ้านหลังนั้น บ้านเลขที่ 38 ยังเป็นหลังเดิมเสมอ แต่ "ผู้อยู่อาศัย" จะเปลี่ยนไปตามภาษาที่ตั้งไว้

## 1. คีย์บอร์ดและภาษา

| คำ | ความหมายแบบง่าย | ตัวอย่าง |
|---|---|---|
| **Layout** (แป้นพิมพ์) | กฎว่าแต่ละปุ่มพิมพ์ตัวอะไรออกมา | แป้นอังกฤษ, แป้นไทย |
| **QWERTY / US** | แป้นภาษาอังกฤษมาตรฐาน ตั้งชื่อตามตัวอักษร 6 ตัวแรกบนแถวบน | ปุ่ม L พิมพ์ `l` |
| **เกษมณี (Kedmanee)** | แป้นภาษาไทยมาตรฐานที่คนไทยเกือบทุกคนใช้ | ปุ่ม L พิมพ์ `ส` |
| **พิมพ์ผิดแป้น / ลืมเปลี่ยนภาษา** | ตั้งใจพิมพ์ภาษาหนึ่ง แต่เครื่องตั้งเป็นอีกภาษา | ตั้งใจพิมพ์ "สวัสดี" แต่ได้ `l;ylfu` |
| **Keycode** | **หมายเลขประจำปุ่ม** ไม่ขึ้นกับภาษา | ปุ่ม L คือหมายเลข 38 เสมอ |
| **Keysym** | **ชื่อเรียก**ของสิ่งที่ปุ่มพิมพ์ออกมาในภาษานั้น อยู่ระหว่างหมายเลขปุ่มกับตัวอักษร | ปุ่ม 38 บนแป้นไทยชื่อ `Thai_sosua` ซึ่งก็คือ `ส` |
| **xkb** | ระบบของ Linux ที่เก็บกฎของแป้นพิมพ์ทุกภาษา | ไฟล์ของแป้นไทยอยู่ที่ `/usr/share/X11/xkb/symbols/th` |
| **Modifier** | ปุ่มที่กดค้างแล้วเปลี่ยนความหมายของปุ่มอื่น | Shift, Ctrl, Alt, Super (ปุ่มรูป Windows) |
| **Super+Space** | ปุ่มลัดสลับภาษาบนเครื่องที่ใช้ทำโปรเจกต์ | กดปุ่ม Windows ค้างแล้วกด Space |
| **สระ/วรรณยุกต์ที่ต้องเกาะ** (combining character) | ตัวอักษรที่ต้องมีพยัญชนะนำหน้าจึงจะแสดงผลได้ | `ิ ี ่ ้` ถ้าพิมพ์เดี่ยวๆ อาจมองไม่เห็น |

## 2. ระบบรับการกดปุ่มของ Linux

| คำ | ความหมายแบบง่าย |
|---|---|
| **Linux / Linux Mint** | ระบบปฏิบัติการ (คล้าย Windows หรือ macOS) Linux Mint เป็นรุ่นหนึ่งของ Linux ที่ใช้ทำโปรเจกต์นี้ |
| **Cinnamon** | หน้าตาเดสก์ท็อปของ Linux Mint ได้แก่เมนู, แถบงาน, หน้าต่าง |
| **Kernel** | แกนกลางของระบบปฏิบัติการ เป็นส่วนที่คุยกับฮาร์ดแวร์โดยตรง |
| **evdev** | ช่องทางที่ kernel แจ้งว่า "มีปุ่มถูกกด" ส่งมาเป็นหมายเลขปุ่ม โปรแกรมของเราใช้ช่องทางนี้**ฟัง**ว่าผู้ใช้กดอะไร |
| **uinput** | วิธีสร้าง**คีย์บอร์ดปลอม**ในเครื่อง สิ่งที่พิมพ์ผ่านคีย์บอร์ดปลอมนี้ เครื่องจะเห็นเหมือนคนกดจริง โปรแกรมของเราใช้มัน**ลบและพิมพ์ใหม่** |
| **Event** | ข้อมูลการกดหรือปล่อยปุ่ม 1 ครั้ง |
| **สิทธิ์ (permission)** | กฎว่าใครทำอะไรกับเครื่องได้บ้าง การฟังคีย์บอร์ดต้องได้รับอนุญาตก่อน เพราะเป็นเรื่องความปลอดภัย |
| **กลุ่ม `input`** | กลุ่มผู้ใช้ที่ได้รับอนุญาตให้ฟังคีย์บอร์ด |
| **udev rule** | ไฟล์ตั้งค่าที่บอกระบบว่าอุปกรณ์ไหนให้ใครใช้ได้ |
| **Logout / Login** | ออกจากระบบแล้วเข้าใหม่ จำเป็นเมื่อเปลี่ยนสิทธิ์ เพราะสิทธิ์ใหม่จะมีผลกับการ login ครั้งถัดไป |
| **gsettings** | ที่เก็บค่าตั้งของเดสก์ท็อป ทดลองแล้วพบว่าค่าภาษาในนี้**ไม่ตรงกับความจริง** จึงไม่ได้ใช้ |
| **Panel / applet** | แถบด้านล่างจอ และปุ่มเล็กๆ บนแถบนั้น เช่น ปุ่มแสดงภาษา EN/TH |

## 3. ระบบหน้าจอ

| คำ | ความหมายแบบง่าย |
|---|---|
| **Display server** | โปรแกรมกลางที่รับการกดปุ่ม/เมาส์ แล้วส่งต่อให้โปรแกรมที่ถูกต้อง และวาดหน้าต่างทุกบานบนจอ |
| **X11** | display server รุ่นเก่า โปรแกรมหนึ่งแอบดูการพิมพ์ในโปรแกรมอื่นได้ง่าย สะดวกแต่ไม่ค่อยปลอดภัย |
| **Wayland** | display server รุ่นใหม่ กันไม่ให้โปรแกรมแอบดูกัน ปลอดภัยกว่า แต่ทำให้เราต้องฟังคีย์บอร์ดจากระดับที่ลึกกว่า (evdev) |
| **Session** | การ login 1 ครั้ง เลือกได้ที่หน้า login ว่าจะใช้ X11 หรือ Wayland |
| **X RECORD / XTest** | เครื่องมือของ X11 สำหรับดักและจำลองการกดปุ่ม ใช้บน Wayland ไม่ได้ |
| **IBus / Fcitx5** | โปรแกรมช่วยพิมพ์ภาษาที่ซับซ้อน เช่น จีน ญี่ปุ่น |
| **Daemon** | โปรแกรมที่รันอยู่เบื้องหลังตลอดเวลาโดยไม่มีหน้าต่าง โปรแกรมแก้ภาษาของเราจะเป็น daemon |
| **Terminal** | หน้าต่างสำหรับพิมพ์คำสั่งให้คอมพิวเตอร์เป็นตัวอักษร |

## 4. ข้อมูล (Data)

| คำ | ความหมายแบบง่าย | ในโปรเจกต์นี้ |
|---|---|---|
| **Corpus** | คลังข้อความจำนวนมากที่เก็บมาจากแหล่งจริง | บทความ Wikipedia, ข้อความโซเชียล |
| **Dataset** | ชุดข้อมูลที่จัดเตรียมไว้ให้โมเดลเรียน มีทั้งโจทย์และคำตอบ | ไฟล์ `train.jsonl` |
| **Label** | "เฉลย" ของแต่ละตัวอย่าง | `ok` = พิมพ์ถูกแป้น, `wrong` = พิมพ์ผิดแป้น |
| **Prefix** | ส่วนต้นของคำ นับจากตัวแรก | คำว่า `hello` มี prefix คือ `h`, `he`, `hel`, `hell`, `hello` |
| **Hard negative** | ตัวอย่างที่**พิมพ์ถูก แต่ดูแปลก**จนอาจหลอกให้ระบบคิดว่าพิมพ์ผิด | รหัสผ่าน `xK9!q2`, คำสั่ง `git`, คำย่อ `ok` |
| **Train / Val / Test** | แบ่งข้อมูลเป็น 3 ส่วน เหมือนการเรียน: **แบบฝึกหัด** (train), **ข้อสอบย่อย**ไว้ปรับวิธี (val) และ**ข้อสอบจริง**ไว้วัดผลครั้งสุดท้าย (test) | แบ่ง 80% / 10% / 10% |
| **Data leakage** (ข้อสอบรั่ว) | ข้อสอบจริงหลุดไปอยู่ในแบบฝึกหัด ทำให้คะแนนสูงเกินจริง | เป็นเหตุผลที่ต้องแบ่งข้อมูลตามบทความ |
| **Balance** | จัดให้แต่ละกลุ่มมีจำนวนพอๆ กัน | `ok` กับ `wrong` อย่างละครึ่ง |
| **Shuffle** | สับลำดับข้อมูลแบบสุ่ม เหมือนสับไพ่ | |
| **Seed** | "เลขตั้งต้น" ของการสุ่ม ใช้เลขเดิมจะได้ผลสุ่มเหมือนเดิมทุกครั้ง | seed = 42 |
| **Data augmentation** | สร้างตัวอย่างหลากหลายขึ้นจากข้อมูลเดิม | สุ่มตัดคำให้สั้นยาวต่างกันทุกรอบ |
| **Hugging Face** | เว็บไซต์ที่รวม dataset และโมเดลให้ดาวน์โหลดฟรี | แหล่งที่โหลด Wikipedia และ Wisesight |
| **Streaming** | โหลดข้อมูลทีละส่วน ไม่ต้องรอโหลดทั้งก้อน เหมือนดูวิดีโอออนไลน์โดยไม่ต้องดาวน์โหลดทั้งไฟล์ | |

## 5. ปัญญาประดิษฐ์ (Machine Learning)

| คำ | ความหมายแบบง่าย |
|---|---|
| **Machine Learning (ML)** | ให้คอมพิวเตอร์เรียนรู้จากตัวอย่าง แทนที่คนจะเขียนกฎเองทุกข้อ |
| **โมเดล (Model)** | "สมอง" ที่ได้จากการเรียนรู้ รับข้อความเข้าไป แล้วตอบว่าพิมพ์ผิดแป้นหรือไม่ |
| **เทรน (Train)** | ช่วงที่โมเดลเรียนจากตัวอย่าง |
| **Classification** | งานจัดกลุ่ม งานนี้มี 2 กลุ่ม (binary) คือ พิมพ์ถูก กับ พิมพ์ผิด |
| **Baseline** | วิธีง่ายๆ ไว้เป็นคู่เทียบ เพื่อดูว่าวิธีที่ซับซ้อนกว่าดีขึ้นจริงไหม |
| **Dictionary lookup** | วิธีเปิดพจนานุกรม: แปลงข้อความแล้วดูว่าเป็นคำที่มีอยู่จริงหรือไม่ |
| **n-gram** | กลุ่มตัวอักษรที่ติดกัน n ตัว เช่น 3-gram ของ `hello` คือ `hel`, `ell`, `llo` |
| **Language model (LM)** | โมเดลที่บอกว่าข้อความนี้ "ดูเป็นภาษานั้น" แค่ไหน เช่น `the` ดูเป็นอังกฤษมาก ส่วน `l;y` ไม่ใช่ |
| **Neural network** | โมเดลที่เลียนแบบการทำงานของเซลล์สมอง เรียนรู้รูปแบบซับซ้อนได้เอง |
| **CNN** | neural network ที่ "ส่องหา" รูปแบบสั้นๆ ทีละช่วง เหมือนใช้แว่นขยายกวาดไปตามข้อความ เป็นโมเดลหลักของโปรเจกต์ |
| **RNN / GRU / LSTM** | neural network ที่อ่านข้อความทีละตัวและจำสิ่งที่อ่านมาแล้ว เหมือนคนอ่านหนังสือ GRU กับ LSTM เป็นรุ่นที่จำได้ดีกว่า RNN ธรรมดา |
| **Transformer** | neural network ขนาดใหญ่ที่ใช้ใน ChatGPT ใหญ่เกินไปสำหรับงานนี้ |
| **Embedding** | การแปลงตัวอักษรแต่ละตัวเป็นชุดตัวเลข ให้โมเดลคำนวณได้ |
| **Parameter** | ตัวเลขภายในโมเดลที่ปรับระหว่างเทรน โมเดลของเรามีไม่ถึง 200,000 ตัว (ChatGPT มีหลายแสนล้าน) |
| **Epoch** | การเรียนแบบฝึกหัดครบทุกข้อ 1 รอบ |
| **Learning rate** | "ขนาดก้าว" ในการปรับโมเดลแต่ละครั้ง ก้าวใหญ่ไปอาจพลาดเป้า ก้าวเล็กไปก็เรียนช้า |
| **GPU** | การ์ดจอ คำนวณหลายอย่างพร้อมกันได้ จึงเทรนโมเดลเร็วกว่า CPU มาก |
| **ONNX** | รูปแบบไฟล์โมเดลกลาง เทรนบน Windows แล้วนำไปใช้บน Linux ได้ |
| **Bayes / Bayesian** | วิธีคิดความน่าจะเป็นที่รวม "สิ่งที่เห็น" เข้ากับ "สิ่งที่รู้อยู่ก่อน" เช่น ปกติคนพิมพ์ผิดแป้นไม่บ่อย |
| **Noisy channel model** | กรอบคิดที่มองว่าข้อความถูก "บิดเบือน" ระหว่างทาง แล้วพยายามเดาข้อความต้นฉบับ |

## 6. การวัดผล

| คำ | ความหมายแบบง่าย | ตัวอย่าง |
|---|---|---|
| **ความมั่นใจ (probability, p)** | คะแนน 0–1 ที่โมเดลให้ว่าพิมพ์ผิดแป้นแค่ไหน | `l;y` ได้ 0.99 แปลว่ามั่นใจมาก |
| **เกณฑ์ (threshold, τ)** | คะแนนขั้นต่ำก่อนระบบจะลงมือแก้ | ตั้ง τ = 0.99 แปลว่าแก้เฉพาะเมื่อมั่นใจ 99% ขึ้นไป |
| **k_min** | จำนวนตัวอักษรขั้นต่ำที่ต้องพิมพ์ก่อนระบบจะเริ่มตัดสิน | ถ้าพิมพ์แค่ตัวเดียว ข้อมูลยังน้อยเกินไป |
| **Precision** | ทุกครั้งที่ระบบแก้ **แก้ถูกกี่ %** | แก้ 100 ครั้ง ถูก 99 ครั้ง = 99% |
| **Recall** | ข้อความที่พิมพ์ผิดแป้นจริง **ระบบจับได้กี่ %** | ผิดจริง 100 ครั้ง จับได้ 90 = 90% |
| **False positive** | ระบบไป**แก้ทั้งที่ผู้ใช้พิมพ์ถูก** เป็นความผิดพลาดที่น่ารำคาญที่สุด | พิมพ์ `git` แล้วถูกแปลงเป็น `เระ` |
| **FPR** | สัดส่วนของ false positive | |
| **Chars-to-detect** | ต้องพิมพ์ไปกี่ตัว ระบบถึงรู้ว่าพิมพ์ผิดแป้น **ยิ่งน้อยยิ่งดี** | `l;y` = 3 ตัว |
| **Latency** | เวลาที่ระบบใช้ตอบ | ต้องไม่ถึง 5 มิลลิวินาที (ms) |
| **ms (มิลลิวินาที)** | 1/1000 วินาที คนพิมพ์ห่างกันประมาณ 100 ms ต่อปุ่ม | |
| **p50 / p99** | เวลาที่ 50% / 99% ของครั้งที่วัด ทำได้เร็วกว่าหรือเท่ากับค่านี้ p99 คือกรณีช้าเกือบที่สุด | |
| **Realtime** | ตอบทันก่อนผู้ใช้จะกดปุ่มถัดไป | |
| **Error analysis** | ดูตัวอย่างที่ระบบทำผิด แล้วหาว่าผิดเพราะอะไร | |

## 7. ข้อความและไฟล์

| คำ | ความหมายแบบง่าย |
|---|---|
| **Unicode** | มาตรฐานสากลที่ให้เลขประจำตัวกับตัวอักษรทุกตัวในโลก เช่น `ส` คือ U+0E2A |
| **UTF-8** | วิธีเก็บตัวอักษร Unicode ลงไฟล์ ตัวอักษรไทย 1 ตัวใช้พื้นที่ 3 ช่อง (byte) |
| **cp874** | วิธีเก็บตัวอักษรไทยแบบเก่าที่ Windows ภาษาไทยยังใช้ ถ้าเปิดไฟล์ผิดวิธีจะเห็นเป็นตัวอักษรเพี้ยน |
| **`�`** | สัญลักษณ์ที่แสดงเมื่อตัวอักษรถูกตัดขาดหรืออ่านผิดวิธี |
| **JSONL** | ไฟล์ข้อความที่เก็บข้อมูล 1 รายการต่อ 1 บรรทัด |
| **Parquet** | ไฟล์ตารางแบบบีบอัด ที่ Hugging Face ใช้เก็บ dataset |

## 8. การพัฒนาโปรแกรม

| คำ | ความหมายแบบง่าย |
|---|---|
| **Python** | ภาษาโปรแกรมที่ใช้เขียนโปรเจกต์นี้ |
| **Library** | ชุดโค้ดสำเร็จรูปที่คนอื่นเขียนไว้ให้ใช้ |
| **uv** | โปรแกรมติดตั้งและจัดการ Python กับ library |
| **Script** | ไฟล์โปรแกรมที่สั่งรันเพื่อทำงานอย่างหนึ่ง เช่น ดาวน์โหลดข้อมูล |
| **Test (unit test)** | โปรแกรมที่ตรวจว่าโปรแกรมหลักทำงานถูกต้อง รันซ้ำได้ทุกครั้งที่แก้โค้ด |
| **Bug** | ข้อผิดพลาดในโปรแกรม |
| **Spike** | การทดลองสั้นๆ (ประมาณ 30 นาที) เพื่อตอบคำถามว่า "วิธีนี้ทำได้จริงไหม" ก่อนลงมือทำจริง |
| **Demo** | การสาธิตให้เห็นว่าระบบทำงานได้จริง |
| **git / commit / GitHub** | git บันทึกประวัติการแก้ไขโค้ด commit คือการบันทึก 1 ครั้ง ส่วน GitHub คือเว็บที่เก็บสำรองโค้ด |
| **Buffer** | ที่เก็บชั่วคราวของตัวอักษรที่ผู้ใช้เพิ่งพิมพ์ในคำปัจจุบัน |
| **Bijection** | การจับคู่แบบ 1 ต่อ 1 ครบทุกตัว แปลงไปแล้วแปลงกลับได้ของเดิมเสมอ |
| **Round trip** | การแปลงไปแล้วแปลงกลับ เพื่อตรวจว่าข้อมูลไม่หาย |
| **Mermaid** | วิธีวาดแผนภาพด้วยการพิมพ์ข้อความ ใช้ในไฟล์ FLOW.md |
| **WSL2** | วิธีรัน Linux อยู่ข้างใน Windows |
